# Web agent authoring

Users demonstrate a browser task, review its Draft and test what the web agent will do.

## Language

**Draft**:
The editable description of a web agent's task, including its demonstrated Steps and chosen Completion criterion. Reopening a Draft does not change what successful execution means.
_Avoid_: Recording, executable configuration

**Completion criterion**:
The user's existing condition for considering a web agent's task complete. It can be a downloaded file, exact screen text, a described outcome, routed email or a demonstrated click.
_Avoid_: Engine success, generic download requirement

**Step**:
One reviewed instruction describing what the web agent should do during the demonstrated task.
_Avoid_: Recorded event, selector
